# Reference Assets

이 폴더는 영상 재현을 위한 원본 Reference를 보관한다.

권장 파일명:

```text
warehouse_reference.mp4
```

원본 영상은 용량/저작권/공개 Repository 정책에 따라 Git에 직접 Commit하지 않아도 된다.
로컬 개발 환경에서는 다음 위치에 두면 된다.

```text
reference/warehouse_reference.mp4
```

Reference 분석 원칙은 `../VIDEO_ANALYSIS.md`를 따른다.

영상에서 직접 확인되지 않는 객체의 산업적 의미를 임의로 확정하지 않는다.
